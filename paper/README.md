## Abstract

Software engineering projects frequently suffer from architectural re-invention, encapsulating functional knowledge within individual project silos. This paper presents Capability-Oriented Software Engineering (COSE), a formal incremental methodology designed to systematically convert software engineering effort into a cumulative, permanent library of reusable, decoupled capabilities.

COSE establishes a mathematical framework for problem decomposition into single-responsibility micro-problems, resolved via deterministic or cognitive capabilities assembled into execution pipelines.
